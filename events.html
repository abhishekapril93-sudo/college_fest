Event Descriptions

1. Code Sprint

A competitive programming contest where participants solve algorithmic problems within a time limit. Teams of up to 3 members can participate. Languages allowed: C, C++, Java, and Python.

2. Robo Wars

Build and battle your robots in an arena. Teams design their own robots and compete in a knockout-style tournament. Robots must weigh under 5 kg and follow the safety guidelines.

3. Web Design Challenge

Participants are given a theme and must design a complete website within 3 hours using HTML, CSS, and JavaScript. Judged on creativity, responsiveness, and code quality.

4. AI Workshop

A hands-on workshop on building machine learning models using Python and scikit-learn. Suitable for beginners and intermediate learners. Laptops are required.

5. Tech Quiz

A fast-paced quiz covering topics from computer science, electronics, space technology, and general tech trivia. Teams of 2 members compete in multiple rounds.
